# Templates

These HTML files are reference layouts used by `prompt.md`.

- `PROGRAMMER_DAILY_TODO_TEMPLATE.html`: programming workflow layout for implementation, verification, commits, and documentation follow-up.
- `ART_DAILY_TODO_TEMPLATE.html`: art workflow layout for pipeline tasks, held items, deliverables, and next-start guidance.

The generated HTML should adapt labels, counts, tags, links, and completion criteria to the evidence for the day. These templates are not meant to be copied as fixed final output without updates.
